# YZI OS — Árvore Documental Ativa

**Esta é a fonte ativa de verdade do YZI OS.**

Toda documentação nova deve ser criada dentro de `docs/yzi-os-active/`. Nenhum documento novo deve ser criado fora desta árvore sem autorização explícita.

---

## Sobre a documentação anterior

A documentação em `docs/` (fora desta árvore) é preservada como **estudos e histórico institucional** — base de pesquisa e referência arquitetural. Ela não é mais fonte ativa de verdade. A triagem e eventual arquivamento formal ficam para etapa futura.

---

## O que o YZI OS não é

- Não é CRM.
- Não é dashboard simples.
- Não é lead manager.
- Não é o projeto Jurema.
- Não é agente de WhatsApp isolado.
- Não é automação de marketing.

---

## O núcleo do YZI OS

**Decisão + ação contínua.**

O YZI OS é o sistema operacional estratégico da empresa. Ele transforma dados, canais, operações e metas em decisões, ações e acompanhamento contínuo.

---

## Primeira implementação ativa

A primeira implementação do YZI OS será na **própria YZIHUB** — usando o YZI OS para gerir a operação e crescimento da YZIHUB. Isso mantém o núcleo livre de estética, regras ou verticais de clientes específicos.
