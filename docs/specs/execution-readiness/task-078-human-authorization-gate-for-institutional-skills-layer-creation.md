## 3. Objetivo do Gate

Este documento prepara uma futura autorização humana para criação documental da camada institucional de skills do YZI OS.

Este gate não cria skills reais, não cria diretório de skills, não cria adapters, não cria `.claude/`, não cria Codex adapter, não cria runner, não cria manifesto machine-readable e não autoriza implementação técnica.

## 4. Futuro Escopo Autorizável

Uma futura task separada poderá, se explicitamente autorizada pelo operador humano, criar apenas:

* Diretório: `/docs/specs/skills/`
* Arquivo inicial: `/docs/specs/skills/README.md`

Esse futuro README deverá ser apenas documental e deverá explicar:

* finalidade da camada de skills;
* diferença entre skill institucional e adapter;
* diferença entre spec, skill, subagente, adapter e executor;
* regra de autoridade;
* proibição de implementação técnica sem autorização;
* que nenhuma skill operacional real estará criada ainda.

## 7. Frases Insuficientes Para Autorização

Essas frases podem indicar conversa, revisão ou preparação, mas não constituem autorização humana explícita para criar `/docs/specs/skills/` ou qualquer artefato associado.
