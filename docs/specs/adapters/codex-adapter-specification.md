# Codex Adapter — Controlled Documentary Specification

This is a controlled documentary specification of the Codex adapter in the YZI OS Research Lab. It is a documentary specification only. It is pure Markdown, with no frontmatter, no YAML, no JSON, no pseudo-schema, and no machine-readable contract. It describes only how a future, separately authorized adapter could translate institutional capabilities and documentary boundaries into instructions compatible with a Codex executor. It creates no executable adapter, no code, no runner, no registry, and authorizes no execution.

## 1. Adapter Specification Title

`codex-adapter`

## 2. Documentary Status

`DOCUMENTARY_SPECIFICATION_ONLY`

## 3. Purpose

This specification exists only to describe, at a documentary and conceptual level, how a future `codex-adapter` could translate the institutional capabilities and documentary boundaries of the YZI OS Research Lab into controlled instructions for a hypothetical Codex executor. It does not implement the adapter, does not produce any executable or machine-readable artifact, and does not authorize any technical or operational use. Any future executable adapter would require its own task, an exact artifact, and explicit human authorization.

## 16. Governance Stop Conditions

A future use of any `codex-adapter` translation must stop and report rather than proceed whenever: the current readiness statement is absent or does not match the expected readiness statement; explicit human authorization is missing or uses only an insufficient phrase; a requested action would fall outside the authorized paths or authorized artifacts; a requested action would create a forbidden artifact (executable adapter, code, runner, registry, YAML, JSON, machine-readable contract); a requested action would alter an approved spec or a P0–P4 package or record; or a requested action would execute Codex, a command, or a subagent without its own task and explicit human authorization. In this task, these stop conditions are documentary only and trigger no execution.
