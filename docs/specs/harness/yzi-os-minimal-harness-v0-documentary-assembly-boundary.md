## 5. Usos Permitidos

Um futuro reference package documental poderá, se autorizado: listar artefatos aprovados; organizar paths canônicos; explicar ordem de uso documental; apoiar criação de prompts futuros; apoiar revisão humana; reduzir erro operacional; preservar rastreabilidade.

Uma futura task só poderá criar o reference package documental se: (1) houver nova autorização humana explícita; (2) criar apenas arquivo documental; (3) listar apenas os oito artefatos elegíveis por path canônico; (4) não criar loader/registry/runner/`.claude/`/hook/MCP; (5) não criar código nem execução automática; (6) preservar implementação técnica em 0%.
