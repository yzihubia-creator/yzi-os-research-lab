# YZI IMOB — Creative Engine + Higgsfield MCP v0.1

## Decisão central

YZI pensa a estratégia. Higgsfield gera o visual. Meta escala. WhatsApp converte. YZI aprende.

## 1. Papel do Creative Engine

O Creative Engine transforma cada imóvel em materiais comerciais: criativos; posts; stories; reels; anúncios; variações visuais; copies; campanhas assistidas.

## 2. Papel da YZI

A YZI entende: imóvel; bairro; público; intenção de busca; silo orgânico; tendência; concorrência; ângulo de venda; copy; campanha.

## 3. Papel do Higgsfield MCP

Higgsfield MCP entra como braço visual para geração de imagem/vídeo. Serve para: transformar estratégia em criativo visual; gerar variações de campanha; criar peças para social; apoiar vídeos curtos; apoiar anúncios; melhorar apresentação visual do imóvel.

## 4. Fluxo

`Imóvel cadastrado → fotos/vídeos enviados → YZI analisa imóvel e define estratégia → YZI gera prompt/briefing visual → Higgsfield gera imagem/vídeo → YZI gera copy/legenda/headline → humano aprova → conteúdo vai para post/campanha → métricas voltam para aprendizado`

## 5. Regra de segurança imobiliária

| Higgsfield pode melhorar | Higgsfield não pode inventar |
|---|---|
| apresentação; formato; letter; recorte; atmosfera; peça publicitária; variação criativa | cômodo; fachada; piscina; varanda; vista; acabamento; metragem; localização; característica física inexistente |

## 6. Regra de aprovação humana

Nenhum criativo gerado por IA deve ser publicado ou usado em anúncio sem aprovação humana.

## 7. Frases internas

- A YZI transforma o imóvel em estratégia. O Higgsfield transforma a estratégia em criativo.
- A YZI pensa. O Higgsfield produz. O humano aprova. A campanha escala.
- Criativo não pode mentir sobre o imóvel.
- Todo criativo precisa nascer da pasta comercial do imóvel.
